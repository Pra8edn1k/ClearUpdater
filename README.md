> **Transparent software version tracking with fully user-controlled update scripts.**

ClearUpdater is a portable Windows application that monitors installed software for new versions and gives you full control over how updates are handled.

Instead of downloading and installing updates automatically, ClearUpdater lets you define exactly what should happen when a new version is available.

**No installation or administrator privileges are required.**

---

## ✨ Features

| | Feature | Description |
|---|---|---|
| 🔎 | **Software version tracking** | Detect installed application versions and compare them with the latest available releases. |
| 🌐 | **Multiple version sources** | Retrieve version information using JSON APIs, web page parsing with regular expressions, Atom/RSS feeds, or GitHub API. |
| 🧩 | **User-defined update scripts** | Easily create update workflows by combining predefined visual action blocks through an intuitive interface. |
| 🛡️ | **Trust management** | Independently manage trust for applications, download links, and update scripts. |
